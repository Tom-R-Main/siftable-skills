# Map Design

Use this reference for cartographic recommendations and map critiques.

## Design Order

1. Purpose: what should the map help someone decide, notice, or do?
2. Audience: what does the reader already know, and what context do they need?
3. Medium: phone, dashboard, print, slide, field use, report, or web app.
4. Scale: what detail is meaningful at the intended zoom or print size?
5. Hierarchy: make the most important spatial message visually dominant.
6. Basemap: include only contextual layers that support the purpose.
7. Symbolization: match data type, geometry, and message.
8. Legend/text: explain calculations, units, classification, and caveats.

## Cartographic Checks

- Use a projection suited to the map's purpose and geography.
- Match classification to data distribution and reader task.
- Choose color ramps for ordered data and distinct hues for categories.
- Check contrast, color vision accessibility, and background interference.
- Avoid decorative marginalia that competes with the message.
- Use labels sparingly and prioritize by importance.
- Design through scale: do not show detail that cannot be read.
- Explain normalized rates differently from raw counts.
