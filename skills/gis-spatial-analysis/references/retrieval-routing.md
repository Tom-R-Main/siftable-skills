# Retrieval Routing

Use these query shapes with an already configured, authorized retrieval backend when useful. No corpus, database, embedding provider, credentials, or query wrapper is bundled. Mix one
architecture query with one domain query for high-stakes design work.

## Custom GIS System

Good query:

```bash
Query: building my own GIS system extract architecture from QGIS MapLibre OpenFreeMap deck.gl
```

Expected source families:

- MapLibre architecture and tile lifecycle for browser rendering and source/tile
  separation.
- QGIS Architecture Notes for project/layer/provider/Processing concepts.
- deck.gl architecture notes and docs for GPU analytical layers.
- OpenFreeMap docs for tile hosting and generation operations.

## Deterministic AI-Guided GIS

Good query:

```bash
Query: deterministic AI guided GIS workflow CRS validation spatial analysis
```

Expected source families:

- AI-Guided GIS With Deterministic Execution.
- How GIS and AI Map Human Survival Transcript.
- GIS Fundamentals for spatial concepts and data-quality context.
