# GIS sources and evidence limits

Use current official documentation and the target project's selected versions:

- [QGIS documentation](https://docs.qgis.org/): Processing, PyQGIS, projects, layouts, providers and CRS behavior.
- [QGIS source](https://github.com/qgis/QGIS): trace code-level claims against an identified revision.
- [GDAL documentation](https://gdal.org/en/stable/): raster/vector drivers, transformation and command semantics.
- [PostGIS documentation](https://postgis.net/documentation/): predicates, measurement, geography and spatial indexes.
- [MapLibre GL JS documentation](https://maplibre.org/maplibre-gl-js/docs/): sources, style, tile/rendering and integration APIs.
- [OpenFreeMap documentation](https://openfreemap.org/): deployment and tile-service choices.
- [deck.gl documentation](https://deck.gl/docs): layer lifecycle, coordinate systems, picking, performance and map integration.

These references are original workflow notes, not bundled manuals or datasets. Their architecture descriptions identify useful questions; check exact APIs against the selected source revision. A configured corpus may supplement primary documentation, but this package provides no database, embedding service, private corpus or ingestion scripts. Do not infer retrieval coverage or current system behavior from these notes. Cite the actual inspected source and preserve uncertainty when an input or runtime is unavailable.
