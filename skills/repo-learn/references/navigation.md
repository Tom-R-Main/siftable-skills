# Choose the cheapest sufficient navigation

| Question | Start here | Escalate when |
|---|---|---|
| Where is the mechanism? | Inventory, literal search, bounded source/test reads | Names are unknown: try conceptual synonyms, manifests, entrypoints. |
| Who calls/implements this across modules? | Imports, caller search, source trace | Use an installed Octocode AST/LSP route or GitNexus graph if lexical inspection leaves a material hidden edge. |
| What belongs in a review context? | A selected file/range list | Repomix can export that selected context when already installed and authorized. |
| Explain a repository to a human | Verified map plus a few causal flows | DeepWiki can present a larger wiki, with explicit indexing/model/runtime costs. |
| What is inside an unavailable dependency? | Existing exact local checkout | opensrc only when acquisition is authorized; independently verify actual revision. |
| What does a compiled binary do? | Existing source/symbols | Ghidra is a binary-analysis lane, with separate runtime and project scope. |

Do not create a new graph engine here. The helper indexes learned patterns, not complete source semantics. A graph can locate evidence; the durable card explains when a mechanism transfers.

At the inspected local revisions:

- **GitNexus:** parser/call/process/community graph, native Tree-sitter and database dependencies; check the selected package’s runtime requirements. `--index-only` still writes `<repo>/.gitnexus` and a global registry. `GITNEXUS_HOME` relocates only global state. Prefer an authorized disposable copy for an evaluation. Check caps and completeness. Static flow is not execution. Its package declares PolyForm Noncommercial; this package copies no GitNexus implementation.
- **Octocode:** bounded content, AST and optional LSP; verify native engine and language-server availability. Owning source forbids lazy managed-server downloads during semantic requests. Zero semantic matches require a lexical/re-anchor fallback. Benchmarked delivered characters are not measured tokens/cost.
- **Repomix:** optional selected-context packaging. Compression can fall back to full text; measure output size. Do not package Git history/diffs by default: its safety path warns but retains suspicious history output. A generated source skill is not distilled engineering knowledge.
- **opensrc:** requested tags/refs can fall back to the default branch and `.git` is removed. A cached version label is insufficient provenance. `path` can acquire missing sources. Existing pinned checkouts are simpler for this collection.
- **DeepWiki:** embeddings/RAG and wiki presentation add services/model costs. In the inspected code, wiki cache keys omit revision; embedding reuse checks vector usability, not source freshness. Keep independent source identities. Citation first-line fallback can mis-anchor repeated code; inspect exact ranges.
- **Ghidra:** valuable reusable ideas include staged analyzers, bounded work, explicit partial completion, and resource release. Running it is unnecessary to learn ordinary source-repository patterns. A timeout can leave completed analyzer results, so “returned output” cannot imply complete analysis.

For an optional-tool trial, freeze representative questions before indexing, use the same source revisions, and record setup cost, source coverage, incorrect claims, tool output bytes and time. Include a later retrieval/application task. Do not call a few handpicked wins a general improvement.
