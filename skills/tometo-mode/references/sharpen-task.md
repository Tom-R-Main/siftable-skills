# Sharpen the task

Use before substantial work or when the user asks to sharpen an approach. Work out the intended outcome, the primary sources and methods an expert would use, and one independent check that could show the result is wrong.

Notice whether the task has too little specification or unnecessary constraints. Resolve implementation facts by reading or a bounded experiment. Simplify self-imposed process that does not serve the goal; propose changes to explicit user constraints rather than silently dropping them. Leave product preferences and irreversible tradeoffs with the user.

Fold useful conclusions into the existing work and continue. Explain framing only when it changes a material assumption or decision. A request only to assess or improve a plan remains plan-only; this preflight grants no new actions, access, or spend.
